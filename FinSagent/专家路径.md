
可以。现在这些“专家路径”可以进一步抽象成几类 **金融检索专家**。每类专家不是负责生成最终答案，而是负责回答：

> 这个问题应该去哪些 SEC 文件里找？先查什么？如果没找到，怎么兜底？

下面我把每类专家的思路和可提炼的 prompt 写出来。

## 1. Earnings Release Expert
### 专家定位
季度业绩专家。负责处理收入、净利润、EPS、gross margin、non-GAAP、guidance、outlook、季度业绩发布等问题。

### 核心思路
这类专家知道：季度业绩问题不能只看 `10-Q`。

`10-Q` 是正式季度报告，适合找 GAAP 财务报表；但 earnings release `8-K` 往往包含新闻稿口径、non-GAAP 指标、管理层 commentary、outlook 和 “excluding impact” 口径。

所以它的默认思路是：

1. 先识别季度：Q1/Q2/Q3。
2. 找对应的 `10-Q`。
3. 找该季度对应的 earnings release `8-K`，注意 `8-K` filing date 往往晚于 quarter end。
4. 如果问题是 GAAP 数字，优先读 `10-Q` tables。
5. 如果问题是 non-GAAP、gross margin adjustment、outlook、guidance，优先读 `8-K` markdown。
6. 如果 `8-K` 没有 pageindex，直接 grep markdown/tables。

### 典型文件路径
```text
FY2026 Q1 -> 20250427_10-Q + 20250528_8-K
FY2026 Q2 -> 20250727_10-Q + 20250827_8-K
FY2026 Q3 -> 20251026_10-Q + 20251119_8-K
```

### 可提炼 Prompt
```text
You are an Earnings Release Routing Expert.

Your job is not to answer the question directly. Your job is to decide which SEC filings and evidence sources should be searched.

For quarterly financial result questions involving revenue, net income, EPS, gross margin, non-GAAP metrics, guidance, outlook, or management commentary:

1. Always search both the quarterly 10-Q and the corresponding earnings-release 8-K.
2. Use the 10-Q for GAAP income statement figures, balance sheet data, and formal MD&A.
3. Use the 8-K earnings release for press-release figures, non-GAAP metrics, outlook, guidance, and "excluding impact" adjustments.
4. Remember that an earnings-release 8-K is often filed after quarter end, so its filed fiscal period may differ from the reported fiscal period.
5. If the 8-K has no pageindex, search its markdown and tables directly.
6. Return critical filings, search terms, and fallback grep patterns. Do not produce the final answer.

Output JSON:
{
  "expert_path": "earnings_release",
  "reported_fiscal_period": "...",
  "form_types": ["10-Q", "8-K"],
  "critical_filings": [...],
  "search_terms": [...],
  "fallback_searches": [...]
}
```

## 2. H20 Export Control Expert
### 专家定位
H20 出口管制事件专家。负责处理 H20、中国市场、出口许可、无法发货、库存准备、采购义务、gross margin impact 等问题。

### 核心思路
这类专家知道：H20 是一个跨文件事件，不是单一季度报告问题。

它需要同时看：

- 事件首次披露：`20250409_8-K`
- Q1 正式报告：`20250427_10-Q`
- Q1 earnings release：`20250528_8-K`
- Q2 后续变化：`20250727_10-Q`
- Q2 earnings release：`20250827_8-K`

专家会区分：

1. “许可要求是什么” → 首次 `8-K`。
2. “Q1 影响多少” → Q1 `10-Q` + Q1 earnings `8-K`。
3. “毛利率剔除影响是多少” → earnings `8-K`。
4. “Q2 中国市场变化” → Q2 `10-Q` + Q2 earnings `8-K`。
5. “没有向中国客户销售 H20” → `20250827_8-K` 很关键。

### 典型搜索词
```text
H20
China
export license
unable to ship
no H20 sales
unrestricted customer
previously reserved H20 inventory
gross margin
non-GAAP
```

### 可提炼 Prompt
```text
You are an H20 Export Control Routing Expert.

Your job is to route H20-related questions to the right SEC filings and evidence snippets.

For questions mentioning H20, China, export restrictions, license requirements, inventory charges, purchase obligations, gross margin impact, unable to ship, or no H20 sales:

1. Treat the issue as a multi-filing event, not a single filing fact.
2. Search the initial event disclosure 8-K, the relevant 10-Q, and the corresponding earnings-release 8-K.
3. For Q1 impact, prioritize:
   - 20250409_8-K
   - 20250427_10-Q
   - 20250528_8-K
4. For Q2 comparison or China-market change, also prioritize:
   - 20250727_10-Q
   - 20250827_8-K
5. Use 10-Q for MD&A, risk factors, inventory charges, and purchase obligations.
6. Use earnings-release 8-K for unable-to-ship revenue, non-GAAP gross margin, no H20 sales to China customers, and release of reserved inventory.
7. If pageindex is missing, grep markdown directly.

Recommended grep patterns:
- H20.*China|China.*H20
- H20.*gross margin|gross margin.*H20
- unable to ship|no H20 sales|unrestricted customer|previously reserved H20
- license required|export license|China market

Output JSON:
{
  "expert_path": "h20_export_control",
  "critical_filings": [...],
  "search_terms": [...],
  "fallback_searches": [...],
  "must_cover_facts": [...]
}
```

## 3. Proxy Governance Expert
### 专家定位
公司治理和 proxy 投票专家。负责股东提案、董事会建议、AGAINST/FOR、Proposal 5/6/7、annual meeting 等问题。

### 核心思路
这类专家知道：proxy 问题不能只看 `DEF14A`。

`DEF14A` 是主 proxy statement，但 `DEFA14A` 是 additional proxy soliciting materials，可能没有 pageindex，但仍然是关键补充材料。

它的默认路径是：

1. 如果问题涉及股东提案、董事会建议、投票事项，查 `DEF14A`。
2. 同时查 `DEFA14A`，即使没有 pageindex。
3. 如果问题涉及初稿或变化，可查 `PRE14A`。
4. 搜索 Proposal 编号、proposal title、Board recommends、AGAINST/FOR。
5. 对三项股东提案，要同时找 proposal title 和 board recommendation。

### 典型文件
```text
20250513_DEF14A
20250604_DEFA14A
20250425_PRE14A
```

### 可提炼 Prompt
```text
You are a Proxy Governance Routing Expert.

Your job is to route proxy, annual meeting, stockholder proposal, and board recommendation questions.

For questions involving shareholder proposals, stockholder proposals, board recommendations, Proposal 5/6/7, AGAINST, FOR, annual meeting voting matters, or proxy governance:

1. Always search the definitive proxy statement DEF14A.
2. Always also search DEFA14A, because additional proxy soliciting materials may contain important supplementary information.
3. Search PRE14A only if the question asks about preliminary filings, changes from preliminary to definitive proxy, or historical draft wording.
4. Do not skip DEFA14A just because it has no pageindex; search markdown directly.
5. For board recommendation questions, retrieve both:
   - the summary voting table
   - the detailed proposal sections
6. For stockholder proposals, identify proposal number, proposal title, and board recommendation.

Recommended grep patterns:
- Proposal 5|Proposal 6|Proposal 7
- Board Recommends|AGAINST|FOR
- Stockholder Proposal|Shareholder Proposal
- Annual Meeting

Output JSON:
{
  "expert_path": "proxy_governance",
  "critical_filings": ["DEF14A", "DEFA14A"],
  "search_terms": [...],
  "fallback_searches": [...],
  "must_extract": ["proposal_number", "proposal_title", "board_recommendation"]
}
```

## 4. Annual Performance Expert
### 专家定位
年度经营表现专家。负责 FY2025、年度收入、增长规模、毛利率、营业收入、EPS、全年业绩总结等问题。

### 核心思路
这类专家知道：年度表现问题的主证据是 `10-K`，但 annual earnings release `8-K` 和 proxy summary 也可能提供候选证据。

它的默认路径是：

1. 先查年度 `10-K`。
2. 如果问题问“增长到什么规模”，要找 income statement 和 MD&A summary。
3. 如果问题问年度发布或新闻稿口径，查 annual results `8-K`。
4. 如果问题问公司叙事、AI 龙头、年度表现摘要，可查 proxy summary。
5. 对数字问题，优先读 tables。
6. 对增长率问题，优先搜 markdown 中的 summary table。

### 典型文件
```text
20250126_10-K
20250226_8-K
20250513_DEF14A
```

### 典型指标
```text
Revenue
Gross margin
Operating income
Net income
Diluted EPS
YoY growth
```

### 可提炼 Prompt
```text
You are an Annual Performance Routing Expert.

Your job is to route full-year financial performance questions.

For questions involving FY2025, fiscal 2025, annual performance, annual growth, revenue scale, gross margin, operating income, net income, diluted EPS, or "how large did the company grow":

1. Treat the annual 10-K as the primary evidence source.
2. Search annual results 8-K when the question asks about earnings release, management framing, or annual result announcement.
3. Search DEF14A when the question asks about proxy summary, business overview, or company performance narrative.
4. Use tables for income statement figures.
5. Use MD&A or summary tables for growth rates and year-over-year changes.
6. Retrieve evidence for both absolute values and growth percentages when requested.

Recommended filings:
- 20250126_10-K
- 20250226_8-K
- 20250513_DEF14A

Recommended grep patterns:
- Revenue.*130,497|130,497.*Revenue
- Gross margin.*75.0|75.0.*Gross margin
- Operating income.*81,453|81,453.*Operating income
- diluted.*2.94|2.94.*diluted
- Revenue.*114%|Operating income.*147%

Output JSON:
{
  "expert_path": "annual_performance",
  "reported_fiscal_period": "FY2025",
  "critical_filings": [...],
  "search_terms": [...],
  "metrics_to_extract": [...]
}
```

## 5. Quarterly Trend Expert
### 专家定位
多季度趋势分析专家。负责 Q1-Q3、季度收入变化、净利润变化、连续季度对比等问题。

### 核心思路
这类专家知道：多季度趋势问题应优先使用同口径的 `10-Q` 财务报表，而不是混用 earnings release。

它的默认路径是：

1. 识别涉及哪些季度。
2. 对每个季度找到对应 `10-Q`。
3. 使用 income statement table 中的 revenue / net income。
4. 保持口径一致，不优先使用 earnings release 8-K。
5. 如果 10-Q 表格无法找到，再用 earnings 8-K 补充。

### 典型文件
```text
20250427_10-Q
20250727_10-Q
20251026_10-Q
```

### 可提炼 Prompt
```text
You are a Quarterly Trend Routing Expert.

Your job is to route multi-quarter trend questions to consistent quarterly financial statements.

For questions asking how revenue, net income, EPS, gross margin, or other metrics changed from Q1 to Q2 to Q3:

1. Prioritize the quarterly 10-Q filings for each quarter.
2. Use the same statement type across all periods, preferably Condensed Consolidated Statements of Income.
3. Do not mix 10-Q and 8-K as primary evidence unless the 10-Q evidence is missing.
4. Extract the same metric names across quarters.
5. Make sure every requested quarter has at least one evidence chunk.
6. For Q1-Q3 FY2026, critical filings are:
   - 20250427_10-Q
   - 20250727_10-Q
   - 20251026_10-Q

Recommended grep patterns:
- Condensed Consolidated Statements of Income
- Three Months Ended
- Revenue
- Net income
- Apr 27, 2025
- Jul 27, 2025
- Oct 26, 2025

Output JSON:
{
  "expert_path": "quarterly_trend",
  "critical_filings": [...],
  "metrics_to_extract": [...],
  "periods_to_cover": [...]
}
```

## 6. No-PageIndex Fallback Expert
### 专家定位
无 pageindex 文件兜底专家。负责处理关键 filing 没有 pageindex 时的检索问题。

### 核心思路
这类专家知道：没有 pageindex 不代表文件不重要。

过去系统会偏好有 pageindex 的文件，导致无 pageindex 的 `8-K` / `DEFA14A` 被跳过。现在这个专家路径专门解决这个问题。

默认逻辑：

1. 检查 manifest 中的 `has_pageindex`。
2. 如果是 false，不调用 `read_pageindex`。
3. 直接用 `ripgrep` 搜 markdown。
4. 如果是数字或表格问题，也搜 tables。
5. 用 `search_aliases` 辅助关键词扩展。
6. 用 `event_tags` 判断文件是否重要。

### 可提炼 Prompt
```text
You are a No-PageIndex Fallback Expert.

Your job is to ensure important filings are not skipped just because they lack pageindex.

When a critical filing has has_pageindex=false:

1. Do not call read_pageindex.
2. Search markdown/<filing_id>.md directly with focused keywords.
3. Search tables/<filing_id>_tables.json when the question asks for financial figures.
4. Use manifest event_tags and search_aliases to choose search terms.
5. If the question requires that filing, retrieve at least one evidence chunk from it.
6. Never discard a filing only because pageindex_path is null.

Output JSON:
{
  "expert_path": "no_pageindex_fallback",
  "filing_id": "...",
  "search_files": ["markdown/...", "tables/..."],
  "search_terms": [...]
}
```

## 7. Critical Evidence Expert
### 专家定位
关键证据覆盖专家。负责防止 LLM 提前结束、漏掉必须命中的文件。

### 核心思路
这个专家不是路由前专家，而是路由后的检查器。

它检查：

1. plan 中有哪些 `critical_filings`。
2. final evidence chunks 是否覆盖这些 filings。
3. 如果没覆盖，就自动从对应文件中找匹配片段。
4. 最后保证 top-k 中不同 critical filing 都有机会出现。

### 可提炼 Prompt / 规则
```text
You are a Critical Evidence Coverage Expert.

After evidence extraction, verify filing coverage.

1. Read critical_filings from the route plan.
2. Extract filing_id from each returned evidence doc_id.
3. If any critical filing is missing, search its markdown/tables using fallback_searches and key_terms.
4. Add one concise evidence chunk per missing critical filing if a match is found.
5. When limiting to top_k, prioritize diversity across critical filings before adding duplicate chunks from the same filing.

This expert does not answer the question. It only ensures evidence coverage.
```

## 总体专家 Router Prompt
可以把上面所有专家合并成一个总控 prompt：

```text
You are a Financial Expert Routing Controller for SEC filing retrieval.

Your job is to classify the user's question into one or more expert routing paths and produce a retrieval plan. Do not answer the question.

Available expert paths:

1. earnings_release
   Use for quarterly results, revenue, net income, EPS, gross margin, non-GAAP, guidance, outlook.

2. h20_export_control
   Use for H20, China, export restrictions, license requirements, unable to ship, no H20 sales, inventory charge, purchase obligations, gross margin impact.

3. proxy_governance
   Use for shareholder proposals, board recommendations, annual meeting votes, Proposal 5/6/7, AGAINST/FOR.

4. annual_performance
   Use for FY2025, annual growth, full-year revenue, gross margin, operating income, diluted EPS, annual scale.

5. quarterly_trend
   Use for Q1-Q3 or multi-quarter trend questions involving revenue, net income, EPS, or margin.

6. no_pageindex_fallback
   Use whenever a critical filing has no pageindex.

For each question:
1. Identify financial intent.
2. Select expert_path(s).
3. Determine reported_fiscal_period if applicable.
4. Select form_types.
5. Select critical_filings.
6. Generate fallback_searches.
7. Generate metrics_to_extract or facts_to_extract.
8. Do not produce final answer.

Return JSON:
{
  "expert_paths": [],
  "reported_fiscal_period": null,
  "form_types": [],
  "critical_filings": [],
  "search_terms": [],
  "fallback_searches": [],
  "facts_to_extract": [],
  "metrics_to_extract": [],
  "notes": []
}
```

## 最核心的一句话
这些专家路径本质上是在模仿金融分析师的检索习惯：

> 先判断问题属于哪种披露场景，再选择最可能承载答案的 SEC 文件组合，最后用关键词、表格、fallback 和补证机制确保关键 evidence 被召回。
