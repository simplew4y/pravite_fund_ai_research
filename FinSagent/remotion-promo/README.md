# FinSagent Remotion Promo

Customer-facing promotional video for FinSagent, built with Remotion.

## Commands

```bash
npm install
npm run studio
npm run poster
npm run render
```

The rendered video is written to:

```text
out/finsagent-promo.mp4
```

The composition is `FinSagentPromo`: 1920x1080, 24fps, 64 seconds.
