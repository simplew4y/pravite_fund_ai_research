# Period and Source Conflict

## When to Use

Use when the question contains a fiscal period and multiple disclosures can conflict.

## Procedure

Prefer period-compatible evidence while retaining later restatements as explicit caveats.

## Verification

Record the selected source and why competing evidence was rejected.
