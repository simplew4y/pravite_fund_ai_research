# Company Profile Boundary

## When to Use

Use for headquarters, ownership structure, holding relationships, and business-scope questions.

## Pitfalls

Company-specific facts belong in governed data, not hidden prompt memory.

## Verification

Require an entity match and in-scope source evidence before changing an answer.
