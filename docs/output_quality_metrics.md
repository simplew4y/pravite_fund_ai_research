# Output Quality Metrics

### 第一组：利润表核心 (Income Statement)

| 编号 | 指标 | 公式 / 定义 | 对应估值模型字段 | 验证方式 | 合格线 |
|------|------|------------|----------------|---------|-------|
| IS1 | 营业收入 | Revenue = 主营业务收入总额 | SALES_IND | 对比原文绝对值 | > 98% |
| IS2 | 营业成本 | Cost of Revenue = 主营业务成本 | COGS_IND | 对比原文 | > 98% |
| IS3 | 毛利润 | Gross Profit = IS1 - IS2 | GP_IND | 验算 IS1 - IS2 | > 98% |
| IS4 | 毛利率 | Gross Margin = IS3 / IS1 × 100% | GROSS_MARGIN_IND | 验算 IS3 / IS1 | > 98% |
| IS5 | 营业利润 (EBIT) | Operating Income | EBIT_IND | 对比原文 | > 98% |
| IS6 | 归母净利润 | Net Income attributable to parent | NP_XORD_IND | 对比原文 | > 98% |
| IS7 | 基本每股收益 | Basic EPS = 归母净利 / 加权平均股本 | EPS_RP_IND | 对比原文或验算 | > 98% |

### 第二组：资产负债表核心 (Balance Sheet)

| 编号 | 指标 | 公式 / 定义 | 对应估值模型字段 | 验证方式 | 合格线 |
|------|------|------------|----------------|---------|-------|
| BS1 | 总资产 | Total Assets = 流动资产 + 非流动资产 | TOT_ASSETS_IND | 对比原文 | > 98% |
| BS2 | 总负债 | Total Liabilities = 流动负债 + 非流动负债 | TOT_LIABS_IND | 对比原文 | > 98% |
| BS3 | 股东权益 | Shareholders' Equity = 总资产 - 总负债 | SHR_EQTY | 验算 BS1 - BS2 | > 98% |
| BS4 | 现金及等价物 | Cash & Cash Equivalents | CASH_IND | 对比原文 | > 98% |
| BS5 | 应收账款 | Accounts Receivable (净额) | ACCTS_REC_IND | 对比原文 | > 98% |
| BS6 | 存货 | Inventory (净额) | INVENTORIES_IND | 对比原文 | > 98% |
| BS7 | 有息负债 | Short-term + Long-term Debt | ST_DEBT_IND + LT_DEBT_IND | 对比原文 | > 98% |

### 第三组：现金流量表核心 (Cash Flow)

| 编号 | 指标 | 公式 / 定义 | 对应估值模型字段 | 验证方式 | 合格线 |
|------|------|------------|----------------|---------|-------|
| CF1 | 经营活动现金流 | Operating Cash Flow | CF_OP_IND | 对比原文 | > 98% |
| CF2 | 资本开支 | Capital Expenditure (绝对值) | CAPEX_IND | 对比原文 | > 98% |
| CF3 | 自由现金流 | FCF = CF1 - CF2 | FCF_IND | 验算 CF1 - CF2 | > 95% |

### 第四组：衍生指标

| 编号 | 指标 | 公式 / 定义 | 数据依赖 | 验证方式 | 合格线 | 备注 |
|------|------|------------|---------|---------|-------|------|
| D1 | 单季营收增速 (YoY) | (当期单季营收 - 上年同期单季营收) / \|上年同期单季营收\| | IS1 单季数据 | 自动计算 + 抽检 | > 95% | |
| D2 | 单季净利润增速 (YoY) | (当期单季净利 - 上年同期单季净利) / \|上年同期单季净利\| | IS6 单季数据 | 自动计算 + 抽检 | > 95% | |
| D3 | 单季营收环比增速 (QoQ) | (当期单季营收 - 上期单季营收) / 上期单季营收 | IS1 单季数据 | 自动计算 + 抽检 | > 95% | |
| D4 | 单季毛利率 | 当期单季毛利 / 当期单季营收 × 100% | IS1, IS3 单季 | 自动计算 + 验算 | > 98% | |
| D5 | 单季毛利率环比变化 | 当期单季毛利率 - 上期单季毛利率 (百分点) | D4 连续两期 | 自动计算 | > 95% | |
| D6 | ROE (年化) | 归母净利润 / 平均股东权益 × 100% | IS6, BS3 | 计算 | > 95% | **存疑**：公式使用平均股东权益，当前模型仅有期末值，需确认平均值的计算方式 |
| D7 | 资产负债率 | 总负债 / 总资产 × 100% | BS2, BS1 | 计算 | > 98% | |

### 第五组：估值与行情指标

| 编号 | 指标 | 公式 / 定义 | 数据来源 | 验证方式 | 合格线 | 备注 |
|------|------|------------|---------|---------|-------|------|
| V1 | Forward PE | 当前股价 / 预期EPS (需标注NTM/FY1/FY2) | 行情接口 + **外部数据：预期EPS** | 验算 | > 90% | 预期EPS需要外部数据源（如同花顺/彭博一致预期），系统自身无法生成 |
| V2 | Trailing PE | 当前股价 / 过去12个月EPS | 行情接口 + IS7 | 计算 | > 95% | |
| V3 | PB (市净率) | 当前股价 / 每股净资产 (BVPS) | 行情接口 + BS3/股数 | 计算 | > 95% | |
| V4 | 近20日日均成交额 | Sum(近20日每日成交额) / 20 | 行情接口 | 验算 | > 98% | |
| V5 | 近20日日均成交量 | Sum(近20日每日成交量) / 20 | 行情接口 | 验算 | > 98% | |
| V6 | 总股本 | 期末普通股总数 (百万股) | SH1 (估值模型) | 对比原文 | > 98% | |
| V7 | 流通市值 | 股价 × 总股本 | 行情接口 + V6 | 计算 | > 95% | |

### 第六组：关键比率验证

| 编号 | 指标 | 公式 / 定义 | 数据依赖 | 验证方式 | 合格线 |
|------|------|------------|---------|---------|-------|
| R1 | 营收同比增速 (年度) | (本年营收 - 上年营收) / 上年营收 | IS1 年度 | 计算 | > 95% |
| R2 | 净利润同比增速 (年度) | (本年净利 - 上年净利) / 上年净利 | IS6 年度 | 计算 | > 95% |
| R3 | EBIT利润率 | EBIT / 营收 × 100% | IS5, IS1 | 计算 | > 95% |
| R4 | 净利润率 | 归母净利润 / 营收 × 100% | IS6, IS1 | 计算 | > 95% |
| R5 | 经营性现金流/营收 | 经营现金流 / 营收 | CF1, IS1 | 计算 | > 95% |

## 估值模型字段对应关系

```
利润表:
  SALES_IND          → IS1
  COGS_IND           → IS2
  GP_IND             → IS3
  GROSS_MARGIN_IND   → IS4
  EBIT_IND           → IS5
  NP_XORD_IND        → IS6
  EPS_RP_IND         → IS7

资产负债表:
  TOT_ASSETS_IND     → BS1
  TOT_LIABS_IND      → BS2
  SHR_EQTY           → BS3
  CASH_IND           → BS4
  ACCTS_REC_IND      → BS5
  INVENTORIES_IND    → BS6
  ST_DEBT_IND + LT_DEBT_IND → BS7

现金流量表:
  CF_OP_IND          → CF1
  CAPEX_IND          → CF2
  FCF_IND            → CF3
```

## 容差规则

| 情境 | 规则 |
|------|------|
| 纯提取 (原文直引) | 取值与原文一致，允许 ±1 最小显示单位 (15.2% → 15.1%~15.3%) |
| 计算值 (增速/比率) | 相对误差 ≤ 0.5% |
| 单位转换 | 百万/亿/元 数值等价即可 |
| 负值基数 | 分母为负时标注"负转正/正转负"，不可直接输出负数百分比 |
