# 当前 UI 组件与操作流程清单

> 版本日期：2026-08-17  
> 分析对象：`omnigent/web` 当前 React 前端，以及本机实际运行的 API 能力配置  
> 用途：作为 UI 重构时的功能范围、组件边界和流程验收基线

## 1. 文档范围

本文只描述：

- 页面、功能组件和它们承担的职责；
- 用户可以执行的操作；
- 操作涉及的状态、权限、异常和数据关系；
- 当前功能是否实际启用、条件启用、仅兼容或尚未接通。

本文不描述：

- 页面布局、组件位置、尺寸和响应式断点；
- 颜色、字体、间距、圆角、阴影、动效等视觉样式；
- UI 重构后的视觉方案；
- 服务端内部实现细节，除非它直接决定 UI 是否可用。

### 1.1 状态标记

| 标记         | 含义                                                           |
| ------------ | -------------------------------------------------------------- |
| **主流程**   | 当前产品入口直接使用，重构时应优先保留                         |
| **条件启用** | 由账号模式、云端能力、桌面端能力、Agent 类型或权限决定是否出现 |
| **兼容入口** | 为旧 URL 或旧数据保留，不再是独立主页面                        |
| **部分可用** | UI 已存在，但当前 API 或运行配置不能完整支持                   |
| **未挂载**   | 代码存在，但当前产品没有入口或没有被渲染                       |

## 2. 当前产品结构结论

当前前端实际上包含两套相互连接的工作域：

1. **私募投研工作台**：项目、资料库、研究会话、研究资产、Memo、估值、历史变化、追踪提醒。这是当前首页的主入口。
2. **通用 Agent 会话工作台**：聊天、文件、终端、子 Agent、任务、执行日志、分享与协作。这套能力仍然存在，并被投研会话复用。

当前首页虽然沿用了“新会话”组件，但代码将 `privateFundResearchEntry` 固定为 `true`。因此首页发起会话时必须先选择投研项目，不能直接创建一个与项目无关的普通会话。

本次运行环境的能力状态为：

- 账号系统关闭；
- 云账号关闭；
- 首次管理员设置关闭；
- 托管沙箱、智能路由、LLM 配置关闭；
- durable jobs、research store、workflow store、insights store 已开启；
- 当前没有可用 Agent，因此“开始研究”按钮处于不可提交状态。

这只是本次运行环境的配置，不代表条件启用页面应从重构范围中删除。

## 4. 全局功能组件

### 4.1 应用启动与能力判断

职责：

- 读取 `/v1/info`，确定账号、注册、沙箱、模型配置、智能路由等能力；
- 初始化身份、主题、语言、查询缓存、会话推送、运行器健康状态和会话状态仓库；
- 根据 `needs_setup`、账号能力和当前路径决定进入设置、认证或主应用；
- 支持普通浏览器、嵌入宿主、桌面端和移动端宿主差异；
- 提供全局提示、图片查看、快捷键和原生安全区适配。

必须保留的状态：能力加载中、能力加载失败、未认证、首次设置、已认证。

### 4.2 应用壳层

职责：

- 承载全局导航、当前页面和会话相关工具；
- 识别当前是否为私募投研会话、普通会话或终端优先会话；
- 管理会话标题、分享、分叉、权限、Agent 信息、文件查看、终端和执行日志等全局操作；
- 管理当前打开的文件、终端、工具视图和会话存活状态；
- 在会话断开、运行器不可达或分叉未绑定时提供恢复入口。

### 4.3 全局导航与会话列表

核心组件：

- 首页/新研究入口；
- 收件箱入口及未处理数量；
- 会话搜索；
- 会话列表：置顶、项目会话、普通会话、共享会话；
- 多选管理；
- 设置/账号入口；
- 投研项目切换和项目资料库。

会话操作：

- 打开、重命名、置顶/取消置顶；
- 归档、删除、停止运行中的会话；
- 从项目中移除；
- 拖动到置顶、项目或非项目分组；
- 全选、批量归档、批量删除；
- 归档会话不在主列表显示，由设置页恢复或永久删除。

必要状态：加载、空列表、搜索无结果、运行中、已停止、删除失败、重试、只读共享会话。

## 5. 私募投研功能组件

### 5.1 项目管理器

职责：

- 搜索、选择并激活投研项目；
- 创建项目；
- 显示项目状态、资料数量和索引状态；
- 编辑项目名称、公司名称、证券代码；
- 删除项目，并明确提示资料、索引、研究资产和输出会同时删除。

当前限制：

- 编辑项目对话框已经存在；
- 当前 canonical API 明确不支持项目更新，因此“编辑项目”属于 **部分可用**；
- 删除属于不可逆操作，重构后仍需显式确认。

### 5.2 全局资料上传

用途：用户尚未选择项目，或一次上传来自不同公司的文件时，由系统自动识别归属。

功能：

- 选择或拖入文件；
- 自动识别公司；
- 匹配已有项目，或自动创建新项目；
- 展示上传、识别、入库、索引的后台任务进度；
- 页面刷新或连接中断后重新连接任务；
- 对未匹配资料进行人工复核和手动改派；
- 识别重复文件、已索引文件、警告和失败；
- 完成后继续上传下一批。

### 5.3 项目资料库

支持的资料类型：PDF、Excel、Word、PowerPoint、CSV、Markdown 和纯文本。

功能组件：

- 项目内上传；
- 文件列表和文件夹分组；
- 创建、重命名、删除文件夹；
- 展开/收起文件夹；
- 拖动文件到其他文件夹；
- 恢复自动分类；
- 文件预览和元数据查看；
- 单文件、整文件夹或全部资料加入“本次提问上下文”；
- 批量选择和批量删除资料。

上传状态机：

`选择文件 → 上传 → 已进入队列 → 索引中 → 完成/失败`

关键约束：上传完成不能只以网络请求成功为准，必须等真实处理与索引任务完成后才能显示完成状态。

### 5.4 新研究会话创建器

用户输入：

- 研究问题；
- 投研项目；
- 常规研究或深度研究；
- 附件；
- 可选技能；
- 条件启用的 Agent、模型、推理强度和运行权限配置。

输入能力：

- 多行文本；
- 回车提交、Shift+回车换行、输入法组合态保护；
- 文件选择、粘贴和拖放；
- 图片、PDF、文本、JSON 附件；
- 语音输入；
- `/` 技能菜单；
- 普通 Agent 会话中的 `@` 文件/文件夹引用；
- 项目状态、资料数量、已索引数量和上下文规模摘要；
- 基于项目资料生成的建议问题。

提交条件：

- 问题非空；
- 已选项目；
- 项目索引就绪；
- 已选可用 Agent；
- 当前没有正在创建会话。

创建结果：

- 激活所选项目并持久化；
- 创建带投研标签和运行配置的会话；
- 将项目约束、研究模式、引用要求、技能和附件合并为首条待发送请求；
- 跳转到 `/c/:conversationId`；
- 会话页加载后自动发送首条研究请求。

### 5.5 研究会话与消息流

消息类型：

- 用户消息；
- Agent 回复；
- 推理过程；
- 工具调用及工具组；
- 命令和终端输出；
- 状态、错误和上下文压缩提示；
- 审批请求、结构化问题和计划评审。

内容渲染能力：

- Markdown、表格、代码、数学公式和 Mermaid；
- 图片及放大查看；
- 引用标记；
- 私募资料中的 PDF/Excel 引用预览；
- 流式输出和工作中状态。

会话操作：

- 发送新问题；
- 中断当前生成；
- 当前生成期间排队后续问题；
- 加载更早消息；
- 在用户消息之间导航；
- 复制回复；
- 从某条回复分叉会话；
- 将回复保存为答案笔记或研究资产；
- 将引用来源标记为可信来源。

异常状态：启动中、连接中、流式生成、已中断、生成失败、会话不存在、运行器不可达、可重连、可克隆恢复、只读。

### 5.6 提问编辑器

除新会话输入能力外，会话内编辑器还负责：

- 按会话保存草稿；
- 问题历史；
- 会话内模型、推理强度、Agent 和计划模式切换；
- Codex 目标创建与状态控制；
- 手动压缩上下文；
- 智能路由/成本控制（能力开启时）；
- 展示当前分支、Agent、项目、模型服务等运行状态；
- 管理本次提问的项目资料与研究资产上下文；
- 选择文本、表格、图表或 Memo 生成方式，并提供额外指令；
- 根据权限和会话标签切换为只读。

### 5.7 私募研究工作台

工作台提供以下功能视图：

| 功能视图 | 主要职责                                   |
| -------- | ------------------------------------------ |
| 研究     | 研究会话、上下文选择、回复转资产、生成控制 |
| 资料     | 管理项目来源文件和研究资产                 |
| 笔记     | 查看、创建和管理研究笔记                   |
| Memo     | 查看当前 Memo、历史版本、打开和下载输出    |
| 估值跟踪 | 管理估值模型、市场快照、历史指标和差异分析 |
| 历史变化 | 比较 Memo 版本，并追踪研究判断的变化       |
| 追踪提醒 | 管理风险、催化剂、提醒、观察规则和治理队列 |

工作台还保存一种内容组织偏好（标签式或 IDE 式）。这是功能偏好，不应和具体布局实现绑定。

工作台依赖两个核心数据集合：项目工作流和研究资产目录。任一数据未就绪时，都必须有明确的加载或错误状态，不能无限等待。

### 5.8 研究资产库

资产类型：

- 来源资料；
- 答案笔记；
- 研究笔记；
- Memo；
- 报告。

资产操作：

- 按标题、摘要和标签搜索；
- 按资产类型、来源类型、笔记类型筛选；
- 按更新时间、最早时间、标题、类型和证据数量排序；
- 切换列表/卡片展示语义；
- 打开、预览、下载；
- 查看当前版本和版本历史；
- 加入或移出本次提问上下文；
- 进入批量管理并删除；
- Memo 按系列聚合版本，默认识别当前版本，并支持比较任意版本。

重要约束：

- “加入提问上下文”的选择状态与“批量管理”的选择状态必须相互独立；
- 删除来源资料的影响大于删除派生笔记，确认信息必须说明会从项目中删除原始资料；
- Memo 版本是同一系列的历史，不应被当成互不相关的普通文件。

### 5.9 研究内容查看器

支持：

- 原始或抽取后的文档；
- PDF、Excel 等来源预览；
- Markdown 研究内容；
- 指标、数据表、折线图和柱状图；
- 受限 HTML 内容；
- 证据来源和引用；
- 相邻资产切换；
- 详细信息展开；
- Memo/报告的打开和下载。

### 5.10 回复转研究资产

功能：

- 从 Agent 回复中选择有用信息；
- 保存为答案笔记或研究节点；
- 当前假设固定入口目前复用“选择有用信息”的行为；
- 选择文本、表格、图表或 Memo 作为下一次生成目标；
- 结合已选资料、资产和会话内容生成；
- 保存后即时更新资产目录，再与服务端结果对齐。

“固定到当前假设”目前没有独立的数据动作，重构时需要明确它是继续作为别名，还是升级为真正的假设关联能力。

### 5.11 Memo 与历史变化

Memo 功能：

- 查看当前版本；
- 查看同系列历史版本；
- 选择任意两个版本进行比较；
- 打开、下载、加入提问上下文；
- 从研究内容生成新 Memo。

历史变化功能：

- 选择 Memo 系列、起始版本和目标版本；
- 交换比较方向；
- 查看新增、变化、本期未提及、未变化的研究项数量；
- 查看新增和移除的证据；
- 标记需要复核的变化；
- 统一或并列差异语义；
- 忽略空白差异；
- 查看论点、假设和指标的版本时间线、状态、数值和证据。

领域约束：**“本期未提及”不等于“已失效”**，重构后不能把二者合并成一个状态。

### 5.12 估值跟踪

功能：

- 选择估值模型；
- 刷新模型数据和市场数据；
- 选择用于估值的来源资料；
- 编辑估值对象和证券身份；
- 查看当前模型版本、处理阶段和诊断信息；
- 查看历史期间；
- 对三个季度指标比较模型值与实际值；
- 查看当前价格和市场快照；
- 查看季度指标差异提醒；
- 让 Agent 分析估值影响，并保留来源证据；
- 查看辅助上下文信息。

领域约束：缺少数据与数值出现差异是两种状态；缺失数据不能自动生成“差异提醒”。

### 5.13 追踪提醒

功能组件：

- 风险、催化剂、待复核、未读提醒摘要及快捷筛选；
- 手动“立即更新”任务；
- 追踪台账搜索、类型筛选、质量筛选和分页；
- 追踪项详情：当前判断、来源、摘录、PDF 内联引用、版本时间线和字段变化；
- 提醒确认和忽略；
- 观察规则创建、编辑和启停；
- 观察规则字段：名称、对象类型、最低影响、频率、关键词、事件类型、变化类型；
- 低质量历史记录治理：查看有效/已归档记录、归档、恢复、永久清除、重建旧数据。

永久清除属于不可恢复操作，必须与普通归档明确区分。

## 6. 通用 Agent 工作区组件

这些能力不是当前首页的独立主入口，但仍在普通会话、投研会话底层能力和条件配置中使用。

### 6.1 普通会话工作区

功能入口：

- 文件；
- 来源引用；
- Agent；
- Shell；
- 任务；
- 执行日志。

工作区负责在会话与这些工具之间同步当前文件、当前 Agent、当前终端和当前任务状态。

### 6.2 文件管理器

功能：

- 查看全部文件或仅查看已修改文件；
- 文件树和文件搜索；
- include/exclude 规则；
- 显示或隐藏隐藏文件；
- 按名称、修改时间、大小、类型排序；
- 切换工作目录；
- 处理主机离线、会话休眠和读取失败状态。

### 6.3 文件查看与编辑

功能：

- 查看代码、Markdown 和其他支持的文件；
- 原始内容与渲染内容切换；
- 编辑、保存和自动保存；
- 未保存内容离开确认；
- 查看修改差异，并切换统一/并列差异语义；
- 添加、查看、定位和处理文件评论；
- 复制文件链接或深链接；
- 上一个/下一个文件；
- 下载文件；
- 从消息、工具调用或评论直接打开文件路径。

编辑权限由会话所有权、共享权限和运行主机状态共同决定。

### 6.4 Shell 与终端

功能：

- 查看终端列表；
- 创建新终端；
- 连接终端 WebSocket；
- 展开、切换、恢复连接和关闭终端；
- 非拥有者只读；
- 终端优先会话可在“聊天”和“终端”语义间切换；
- 普通会话可将 Shell 作为工具打开。

### 6.5 Agent 与子 Agent

功能：

- 查看主 Agent 和子 Agent；
- 查看运行状态和最近输出；
- 在主 Agent、同级 Agent 和子 Agent 之间导航；
- 添加或切换 Agent；
- 创建自定义 Agent；
- 自定义 Provider、模型、API Key、系统提示词和 MCP 服务。

### 6.6 任务与执行日志

任务：展示待办项和状态变化。  
执行日志：展示主会话及子会话的原始执行事件，用于理解 Agent 当前正在做什么或为何失败。

### 6.7 Agent 配置

根据 Agent 类型和服务端能力，可能出现：

- Claude 模型、推理强度和权限模式；
- Codex 审批模式；
- 危险绕过模式及二次文本确认；
- Cursor 执行模式；
- Brain harness 覆盖；
- 智能模型路由和成本控制；
- 主机、沙箱、工作目录、分支和 worktree；
- 自定义 Agent。

私募项目入口会隐藏不适合普通投研用户的主机/工作目录配置，并使用项目绑定的运行环境。

## 7. 协作、恢复与系统辅助组件

### 7.1 会话分享与权限

功能：

- 复制分享链接；
- 按用户或邮箱授权；
- 设置权限级别；
- 更新或撤销权限；
- 显示共享消息作者；
- 按权限决定查看、编辑、分享和管理能力。

限制：本地模式可能不提供分享；只有拥有管理权限或所有权的用户可管理权限。

### 7.2 会话分叉

功能：

- 从当前会话或某条回复创建新会话；
- 选择主机、工作目录、分支、基线和名称；
- 创建成功后跳转到新会话。

### 7.3 断线与恢复

恢复类型：

- 会话运行器不可达：重新连接或克隆；
- 分叉会话未绑定运行目录：选择主机、目录和分支后继续；
- 会话失败：使用指定模型重启；
- 终端断开：恢复连接；
- 页面重载：恢复草稿、上传任务和会话推送。

### 7.4 审批与结构化提问

审批入口：

- 会话中的内联审批卡；
- 收件箱中的待审批列表；
- `/approve/:sessionId/:elicitationId` 独立链接页。

操作：批准、拒绝，以及在支持时记住本次决策。  
结构化提问支持多步骤问题和选项回答，完成后将结果返回运行中的 Agent。

### 7.5 收件箱

内容：

- 待处理审批；
- 未读文件评论。

操作：

- 展开/收起审批；
- 批准、拒绝、记住选择；
- 回答结构化问题；
- 打开对应会话、文件和评论；
- 读取失败时重试。

必须覆盖空收件箱、部分加载失败、已处理和未读数量更新状态。

### 7.6 通用反馈组件

- 确认对话框；
- 错误提示和重试；
- 成功/失败 Toast；
- 图片放大查看；
- 键盘快捷键说明；
- Agent 信息、工具和策略详情；
- 浏览器通知、系统空闲通知和桌面角标。

## 9. 核心操作流程

### 流程 1：应用进入与路由决策

1. 加载服务端能力。
2. 若账号系统开启且系统需要首次设置，进入创建管理员。
3. 若当前是登录、注册或找回密码路径，进入对应认证页。
4. 若当前是独立审批链接，直接加载审批请求。
5. 其余情况进入应用壳层。
6. 根据 URL 加载首页、会话、收件箱、设置或管理页面。

### 流程 2：创建或切换投研项目

1. 打开项目选择器。
2. 搜索并选择已有项目，或输入信息创建项目。
3. 系统激活项目并保存当前项目 ID。
4. 首页、项目资料库和研究会话统一切换到该项目。
5. 系统读取项目资料状态和索引状态，决定是否允许开始研究。

### 流程 3：全局上传并自动归档资料

1. 选择一批资料。
2. 创建后台处理任务。
3. 系统识别公司并匹配已有项目或创建新项目。
4. 系统上传、抽取、入库并建立索引。
5. 用户处理无法自动匹配的资料。
6. 系统按文件显示成功、重复、警告或失败。
7. 用户可继续上传新资料或进入对应项目。

### 流程 4：向当前项目上传资料

1. 在项目上下文中选择文件。
2. 校验格式并开始上传。
3. 文件进入后台队列。
4. 等待内容抽取和索引完成。
5. 更新项目资料数量与索引状态。
6. 成功后资料可预览、分类和加入提问上下文；失败时允许查看原因并重试。

### 流程 5：开始一次研究

1. 选择索引就绪的项目。
2. 输入研究问题，选择常规或深度研究。
3. 可选添加附件、技能和运行配置。
4. 前端验证问题、项目、索引和 Agent 是否就绪。
5. 创建带项目标签的会话。
6. 生成首条投研请求，其中包含项目约束、研究模式和引用要求。
7. 跳转到会话并自动发送。
8. 会话进入连接、生成、完成或失败状态。

### 流程 6：使用资料上下文继续研究

1. 从项目资料库或研究资产库选择文件/资产。
2. 选择项写入当前提问上下文，并在需要时持久化到服务端。
3. 用户选择生成类型并输入补充指令。
4. 提交问题。
5. Agent 使用会话历史和已选上下文生成回答。
6. 回答中的引用可回到原始 PDF、Excel 或研究资产。
7. 用户可以移除上下文，再发起下一轮问题。

### 流程 7：把回答沉淀为研究资产

1. 用户在 Agent 回复上选择“保存答案笔记”或“保存研究资产”。
2. 前端创建派生资产并保留与原会话、原回复和证据的关系。
3. 资产立即出现在研究资产库中。
4. 用户可查看、补充、加入后续提问上下文或删除。
5. 资产可继续参与 Memo、表格、图表或其他研究输出生成。

### 流程 8：生成和比较 Memo

1. 选择项目资料、研究笔记、答案笔记或已有 Memo 作为上下文。
2. 选择 Memo 生成方式并提交要求。
3. 系统生成新 Memo 版本并纳入同一系列。
4. 用户查看当前版本或选择历史版本。
5. 选择起止版本进行比较。
6. 系统展示内容、证据和研究项状态变化。
7. 用户对“本期未提及”和“已失效”分别判断。

### 流程 9：估值跟踪

1. 选择估值模型和来源资料。
2. 刷新模型与市场数据。
3. 检查处理阶段、诊断和缺失数据。
4. 查看历史期间、模型值、实际值和当前市场快照。
5. 对真实差异查看提醒。
6. 请求 Agent 分析估值影响并查看证据。

### 流程 10：追踪风险、催化剂和提醒

1. 进入追踪提醒并查看风险、催化剂、待复核和未读摘要。
2. 搜索或筛选追踪项。
3. 打开详情，查看当前判断、来源、摘录和版本变化。
4. 确认或忽略提醒。
5. 创建或编辑观察规则，设置触发对象、影响阈值、频率和关键词。
6. 必要时手动触发更新。
7. 在治理队列中归档、恢复、清除或重建低质量旧记录。

### 流程 11：普通 Agent 会话

1. 选择 Agent、模型、权限、主机、沙箱和工作目录等条件配置。
2. 创建会话并发送首条请求。
3. Agent 输出消息、推理、工具、命令和计划。
4. 用户审批工具请求或回答结构化问题。
5. 用户可打开 Agent、文件、Shell、任务和执行日志。
6. 会话可停止、重启、分享、分叉、归档或删除。

### 流程 12：文件查看、编辑和评论

1. 从文件树、消息引用、工具调用或收件箱评论打开文件。
2. 查看原始/渲染内容或变更差异。
3. 有权限时编辑并保存；离开前处理未保存内容。
4. 添加或处理评论。
5. 评论产生收件箱未读项；接收者可从收件箱返回文件位置。

### 流程 13：终端操作

1. 打开已有 Shell 或创建新 Shell。
2. 建立终端连接。
3. 拥有者可输入和关闭，其他用户只读。
4. 断线时重连或恢复。
5. 终端优先会话可返回聊天查看 Agent 解释和状态。

### 流程 14：分享与协作

1. 会话所有者或管理者打开权限管理。
2. 复制链接或按用户/邮箱授权。
3. 指定权限等级。
4. 共享用户按权限查看、评论或编辑。
5. 管理者可修改或撤销权限。
6. 消息和文件评论保留作者身份。

### 流程 15：异常恢复

1. 系统识别会话不可达、运行器断开、分叉未绑定、终端断开或任务失败。
2. 向用户说明当前状态和可恢复动作。
3. 用户选择重连、选择目录继续、克隆会话、换模型重启或重试任务。
4. 恢复成功后回到原会话上下文；失败则保留错误详情和再次重试入口。

## 11. 重构时必须保留的功能边界

1. **项目是投研会话的前置上下文**：当前首页不能在无项目时直接开始研究。
2. **索引就绪是可研究条件**：文件上传成功不等于项目可检索。
3. **全局上传与项目内上传是两个不同流程**：前者负责识别公司和路由项目，后者已有明确项目归属。
4. **会话历史、资料上下文和研究资产是三种不同数据**，不可在 UI 状态中混为一体。
5. **提问上下文选择与批量删除选择必须分离**。
6. **来源引用必须可回溯到原始证据**，尤其是 PDF、Excel 和派生研究资产。
7. **Memo 必须有系列与版本概念**，不能只做普通文件列表。
8. **“本期未提及”不能自动解释为“失效”**。
9. **估值缺失数据不能自动解释为估值差异**。
10. **运行中请求需要中断和后续问题排队能力**。
11. **会话需要只读、可编辑、可管理等权限差异**。
12. **上传、生成、更新等长任务需要真实后台状态和断线恢复**。
13. **删除项目、来源资料、会话、成员和治理记录需要不同级别的影响说明**。
14. **邀请链接和管理员重置出的密码只显示一次**。
15. **所有条件功能继续由能力和权限驱动**，不能仅靠隐藏入口代替服务端校验。
16. **旧项目 URL 需要继续兼容跳转**，除非另有迁移方案。
17. **投研会话仍需复用通用 Agent 的消息、工具、审批、文件和运行恢复能力**。

| 事项                        | 当前情况                                                     | 重构决策                                                    |

## 13. 功能验收清单

重构后的 UI 至少应按以下顺序验收：

1. 能力加载、首次设置、登录和主应用路由正确。
2. 能创建、切换、删除项目，并正确处理项目编辑能力。
3. 全局上传能够识别公司、创建/匹配项目和人工改派。
4. 项目内上传能够走完真实索引状态机。
5. 只有项目、索引和 Agent 就绪时才能开始研究。
6. 首条研究问题能自动发送，消息可流式展示、中断和继续追问。
7. 来源引用能打开对应文档位置。
8. 资料和资产能独立搜索、筛选、预览、选入上下文和批量管理。
9. 回复能保存为研究资产，并可参与后续生成。
10. Memo 版本和历史比较保持正确语义。
11. 估值跟踪正确区分缺失与差异。
12. 追踪提醒、观察规则和治理操作完整。
13. 普通 Agent 文件、Shell、子 Agent、任务和执行日志仍可用。
14. 分享权限、评论、收件箱和审批链路完整。
15. 会话断开、运行器不可达、任务失败和失效会话都有明确恢复或退出动作。
16. 条件设置、成员管理和全局策略按能力与权限出现。
17. 所有加载、空、错误、只读、禁用、执行中和破坏性确认状态可验证。

## 15. 核对方式与证据边界

本清单通过三类证据交叉核对：

1. 路由、组件引用、状态管理和 API 调用代码；
2. 相关组件测试；
3. 本机实际运行页面：首页、设置页、收件箱和会话入口。

- `docs/ui-audit-evidence/02-settings.png`
- `docs/ui-audit-evidence/03-inbox.png`

证据限制：

- 本次运行时，私募工作台所需的 workflow 与 assets 接口返回 404，因此研究资产、Memo、估值、历史变化和追踪提醒无法完成端到端页面操作；这些部分以当前组件代码和测试为依据。
- 当前环境没有可用 Agent，因此无法从首页实际完成“创建并运行研究会话”；该流程以创建逻辑、会话自动派发逻辑和测试为依据。
- 一个现存会话 ID 在当前 API 中已不存在，打开时返回 404；它不能作为正常会话流程的运行证据。
