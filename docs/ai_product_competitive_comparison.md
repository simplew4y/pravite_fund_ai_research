# AI 产品竞争对比

| 对比维度 | 通用 AI Chatbot（ChatGPT、Claude 等） | Coze | 我们的私募研究工作台 | 我们的核心优势 |
|---|---|---|---|---|
| 产品定位 | 通用智能助手 | Agent、Bot 和工作流搭建平台 | 私募投研操作系统 | 专注投资研究，而非泛化工具 |
| 主要用户 | 个人、知识工作者、企业员工 | Agent 开发者、运营和业务人员 | 私募研究员、基金经理、投委会成员 | 面向明确的金融业务角色 |
| 核心对象 | 对话、文件、项目 | Bot、插件、工作流、知识库 | 项目、资料、证据、研究节点、Memo、研报 | 将研究对象结构化 |
| 典型使用方式 | 上传文件后提问 | 配置工作流并发布 Agent | 导入资料并持续完成研究、核验和报告 | 覆盖完整投研过程 |
| 资料处理 | 文件作为对话上下文 | 知识库切片与召回 | PDF、Excel、PPT、Word 统一解析入库 | 更适合复杂投研资料 |
| Excel 能力 | 通用读取和数据分析 | 依赖工作流或插件 | 记录 Sheet、区域、单元格、原始值和公式 | 财务数据可精确核验 |
| 证据溯源 | 可提供引用，但粒度和稳定性不固定 | 取决于工作流如何设计 | 绑定文件版本、页码、Sheet、单元格及 `evidence_id` | 每条结论都能回到原始资料 |
| 防止幻觉 | 依赖模型和提示词 | 依赖开发者配置 | Citation Gate 检查报告结论是否有证据 | 将证据要求固化为系统规则 |
| 研究沉淀 | 主要保留聊天和项目上下文 | 保存工作流和运行记录 | 对话结果保存为结构化研究节点和研究资产 | 研究不会随着聊天结束而消失 |
| 历史关系 | 项目记忆和历史对话 | 工作流执行历史 | 节点依赖、证据谱系、报告版本和更新记录 | 可以追踪观点如何形成和变化 |
| 长期研究 | 适合连续对话和项目协作 | 适合自动化长期任务 | 新资料进入后更新旧观点、Memo 和报告 | 支持持续覆盖一家企业或项目 |
| 投研工作流 | 需要用户反复提示 | 用户自行搭建 | 内置资料检索、核验、节点、Memo、估值和报告流程 | 私募研究方法已经产品化 |
| 最终交付 | 通用回答、文档、表格 | Bot、应用、自动化任务 | 投资 Memo、估值指标、研究节点、专业研报、PDF | 直接生成投研业务产物 |
| 专业报告 | 可以生成通用报告 | 需要配置模板和流程 | 基于证据生成版本化专业研报和图表 | 更接近投委会交付标准 |
| Skills 扩展 | GPT、Projects、Apps、MCP 等 | 技能商店、插件、工作流 | 金融 Skills 市场、一键安装、按用户管理 | 扩展能力与投研数据体系结合 |
| 模型选择 | 基本绑定平台模型 | 支持平台提供的多种模型 | 可通过模型网关切换和路由不同模型 | 不依赖单一模型供应商 |
| 数据部署 | 主要使用厂商云服务 | 云平台，也有开源及私有化方向 | macOS 独立运行，本地资料优先 | 更适合未公开项目资料 |
| 用户隔离 | 由平台账号体系管理 | 由平台空间体系管理 | 独立账号、数据集和 Skills 目录 | 用户资料与技能相互隔离 |
| 通用能力 | 非常强 | 强 | 相对有限 | 不与大厂竞争泛化能力 |
| 垂直业务深度 | 通用 | 中等，依赖搭建者 | 深度面向私募研究 | 核心竞争壁垒 |
| 最适合场景 | 临时问答、写作、通用研究 | 快速搭建 Agent、应用和自动化流程 | 内部资料研究、投资逻辑沉淀、投委会报告 | 高价值、长期、证据敏感的投研任务 |
| 一句话总结 | **帮助用户回答问题** | **帮助用户搭建智能体** | **帮助私募机构生产可信研究资产** | **可核验、可积累、可持续更新** |

## 核心定位

> ChatGPT、Claude 帮助用户回答问题，Coze 帮助用户搭建智能体；我们的产品帮助私募机构把内部资料转化为可核验、可积累、可持续更新的投资研究资产。

## 三项核心卖点

1. **结论有证据**
   每条重要结论都能回到真实文件、PDF 页码、Excel Sheet 或单元格。

2. **研究可积累**
   对话内容能够沉淀为结构化研究节点、投资观点和长期研究资产。

3. **报告可持续更新**
   新资料进入后，可以识别变化、更新历史观点并保留报告版本。
