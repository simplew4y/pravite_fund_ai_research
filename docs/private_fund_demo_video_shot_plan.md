# 私募研究 Demo 视频分镜计划

## 1. 视频定位

目标：用一支 90-110 秒的演示视频说明，这套基于 Omnigent 前端的私募研究工作台，如何从本地 PDF 资料完成问答、溯源复核，并生成投资 memo PDF。

受众：私募投研、基金经理、研究助理、产品评审人员。

表达原则：

- 先讲主要功能，再展示必要系统步骤。
- 不深入技术实现，不讲 chunk、MCP、数据库、执行器细节。
- UI 基本复用当前 Omnigent 聊天界面：左侧会话 / 中间聊天框 / 右侧 source 或文件预览面板。
- 所有能力都从一个聊天框发起，不展示单独的 private fund PDF 面板。
- 每个镜头只保留一个主焦点，避免把网页细节塞满整屏。

## 2. 推荐视频规格

- 画幅：16:9 横屏
- 分辨率：1920 x 1080
- 帧率：30 fps
- 总时长：约 100 秒
- 视觉风格：保留当前产品 UI，外层加少量金融研究风格的标题、光标、放大框和高亮标注。
- 字幕策略：每个镜头只出现一句短字幕，旁白承担解释，不在屏幕上堆长段文字。

## 3. 整体叙事

一句话主线：

```text
从本地 PDF 到可信回答，再到可交付 memo，一切都在同一个研究聊天框里完成。
```

建议叙事顺序：

1. 研究员进入私募研究工作台。
2. 在聊天框中指定本地 Tesla PDF 并提出研究问题。
3. 系统给出结构化回答，并在关键判断后附来源。
4. 点击来源，右侧打开 PDF 原文页面并定位相关区域。
5. 继续追问，验证系统可以围绕同一资料做连续研究。
6. 输入 memo 生成指令，系统整理成投资 memo。
7. 展示 memo PDF 预览和来源可复核能力。
8. 收束为价值总结：问答、溯源、memo 交付。

## 4. 关键画面设置

### 4.1 主界面

画面复用当前 Omnigent UI。建议用一个稳定的桌面截图作为基础：

- 中间聊天区占画面主视觉。
- 输入框位于画面底部，镜头需要看清用户输入的 prompt。
- 回答区域要展示 2-3 条清晰 bullet，不需要完整长回答。
- 右侧面板只在溯源和 memo 预览镜头打开。

### 4.2 来源面板

来源效果是视频的核心可信度镜头。画面设计：

- 左侧保留回答中的 citation，如 `[p.113]` 或 `10-K p.113, para.1`。
- 光标点击 citation。
- 右侧 Sources 面板打开 PDF 页面。
- PDF 页面上有高亮框，镜头轻微放大到高亮区域。
- 屏幕短字幕：`点击来源，回到原始 PDF 页面`。

### 4.3 Memo 生成画面

memo 生成不展示内部过程，只展示用户体验：

- 用户在同一个聊天框输入：`基于本地 Tesla PDF 生成投资 memo PDF`。
- 系统状态可简化为三步：`整理材料`、`形成观点`、`生成 PDF`。
- 最后右侧打开 memo PDF 预览，左侧聊天区出现下载或完成提示。

```text
这是一套面向私募投研的本地研究助手。

研究员不需要在多个工具之间切换，只要在同一个聊天框里提出问题。

系统会围绕本地 PDF 资料组织回答，并保留可复核来源。

比如基于 Tesla 的本地文件，先概括当前核心投资逻辑。

回答会先给结论，再拆成收入结构、增长驱动和主要风险。

研究过程也可以继续追问，比如收入结构、能源业务、自动驾驶进展和风险因素。

当结论基本成型，可以直接要求生成投资 memo。

系统会把问答、资料和引用整理成可交付的 memo PDF。

从资料阅读到可信问答，再到 memo 生成，完整投研流程都在一个界面里完成。
```

## 9. Remotion 实现建议

这部分只作为后续制作依据，不需要在成片中展示。

- 使用一个主 Composition：`PrivateFundDemoVideo`。
- 用 `Sequence` 分镜，每个镜头按上方时间切分。
- 用当前 Omnigent 页面截图或录屏片段作为主要视觉资产。
- 动画用 `useCurrentFrame()` + `interpolate()` 控制透明度、位移和缩放。
- 不使用 CSS transition 或 Tailwind animation。
- 重要文字放在 80px 以上安全边距内。
- 主标题建议 84px 左右，镜头字幕 44px 左右，局部标签 32px 左右。
- 不让 UI 小字承担解释功能；产品细节由旁白解释。
