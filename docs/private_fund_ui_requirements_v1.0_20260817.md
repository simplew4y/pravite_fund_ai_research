# 私募投研 AI 工作台 UI 功能说明

本文用于说明 UI 重构需要包含的功能、组件和主要业务流程，不涉及具体布局与视觉样式。

## 一、功能模块

### 1. 项目管理

- 创建、搜索、选择和切换投研项目。
- 查看项目名称、公司、证券代码、资料数量和索引状态。
- 编辑项目信息。
- 删除项目，并提示资料、索引、研究资产和输出的影响。
- 当前项目作为资料、会话、资产、Memo、估值和追踪的统一范围。

### 2. 资料上传与管理

- 支持 PDF、Excel、Word、PowerPoint、CSV、Markdown 和文本文件。
- 支持全局上传，自动识别公司并匹配或创建项目。
- 支持项目内上传，文件直接归入当前项目。
- 展示上传、排队、解析、索引、完成、警告和失败状态。
- 对无法识别公司或存在冲突的资料进行人工确认和改派。
- 创建、重命名和删除资料文件夹。
- 移动文件、恢复自动分类、搜索、预览和查看元数据。
- 单个、整组或全部资料加入本次提问上下文。
- 批量选择和删除资料。

### 3. 新建研究

- 选择研究项目。
- 输入研究问题。
- 选择常规研究或深度研究。
- 添加附件、使用语音输入或调用技能。
- 展示项目资料数量、索引状态和建议问题。
- 在需要时选择 Agent、模型和推理配置。
- 项目、索引和 Agent 就绪后创建研究会话。

### 4. 研究会话

- 展示用户消息、Agent 回复、推理过程、工具调用、命令和运行状态。
- 支持 Markdown、表格、代码、数学公式、Mermaid 和图片。
- 发送问题、中断生成、排队后续问题和加载历史消息。
- 保存会话草稿和问题历史。
- 复制回复或从某条回复创建分叉会话。
- 处理审批请求、结构化问题和计划评审。
- 显示连接、生成、完成、中断、失败和只读状态。
- 会话断开时支持重连、克隆或换模型重启。

### 5. 引用与来源复核

- 在回答中展示可点击引用。
- PDF 引用定位到文件和页码。
- Excel 引用定位到工作簿、Sheet、范围或单元格。
- 展示原值、公式和附近上下文。
- 支持 Office、文本和研究资产来源预览。
- 区分来源失效、索引缺失、范围为空和跨项目引用。
- 支持将来源标记为可信来源。

### 6. 提问上下文

- 从项目资料和研究资产中选择本次问题使用的上下文。
- 查看当前已选资料、资产和上下文数量。
- 添加或移除单个资料、文件夹或资产。
- 将上下文选择同步到后续 Agent 请求。
- 提问上下文选择与批量删除选择相互独立。

### 7. 研究资产

- 统一管理来源资料、答案笔记、研究笔记、Memo 和报告。
- 按标题、摘要、标签和类型搜索或筛选。
- 按更新时间、标题、类型和证据数量排序。
- 打开、预览、下载和删除资产。
- 查看当前版本和历史版本。
- 将资产加入后续提问上下文。
- 将整条回复或选中内容保存为答案笔记或研究资产。
- 基于资料、资产和会话生成文本、表格、图表或 Memo。

### 8. Memo 与历史变化

- 生成或修订 Memo。
- 查看当前 Memo 和历史版本。
- 打开、下载或加入提问上下文。
- 选择任意两个版本进行比较。
- 展示新增、变化、本期未提及、未变化和待复核内容。
- 展示新增、移除的证据及其来源。
- 查看论点、假设和指标的版本时间线。
- “本期未提及”与“已失效”保持为不同状态。

### 9. 估值跟踪

- 选择估值模型和相关来源资料。
- 刷新模型数据和市场数据。
- 查看当前模型版本、处理进度和诊断信息。
- 查看历史期间、季度指标和当前市场快照。
- 比较模型值与实际值。
- 查看真实差异提醒，并区分数据缺失。
- 请求 Agent 分析估值影响并查看证据。
- 生成派生模型，经用户确认后加入项目资料。

### 10. 风险、催化剂与追踪提醒

- 查看风险、催化剂、待复核项和未读提醒。
- 搜索并按类型、质量筛选追踪项。
- 查看当前判断、来源、摘录和版本变化。
- 确认或忽略提醒。
- 创建、编辑、启用或停用观察规则。
- 配置影响程度、更新频率、关键词和事件条件。
- 手动触发追踪更新并查看任务状态。
- 归档、恢复、清除或重建低质量历史记录。

### 11. 会话与协作

- 搜索、打开、重命名、置顶、归档、停止和删除会话。
- 对会话进行批量归档或删除。
- 复制分享链接并按用户或邮箱授权。
- 设置、修改或撤销查看、评论、编辑和管理权限。
- 展示共享会话中的消息作者。
- 在文件中添加和处理评论。

### 12. 收件箱与审批

- 聚合待处理审批和未读文件评论。
- 批准或拒绝 Agent 操作请求。
- 回答多步骤结构化问题。
- 从评论通知打开对应会话、文件和评论位置。
- 支持独立审批链接。
- 展示空、加载失败、已处理和未读数量状态。

### 13. 通用 Agent 工作区

- 查看全部文件或已修改文件。
- 搜索、过滤、排序文件和切换工作目录。
- 查看、编辑、保存和下载文件。
- 查看文件差异和处理文件评论。
- 查看主 Agent、子 Agent、运行状态和最近输出。
- 创建、连接、切换和关闭 Shell。
- 查看任务和执行日志。
- 配置 Agent、模型、权限、主机、沙箱、目录、分支和 worktree。

### 14. 设置与管理

- 语言、生成内容语言、主题和快捷键设置。
- 技能搜索、安装、卸载和来源查看。
- 查看、恢复或永久删除归档会话。
- 账号信息、昵称、密码和退出登录。
- 模型来源、平台用量、反馈和 LLM Provider 配置。
- 桌面端 Local CLI 状态和路径设置。
- 管理员邀请成员、重置密码和删除成员。
- 管理员添加、配置、启停和删除全局策略。

### 15. 异常与恢复

- 处理项目、会话、资料或来源不存在。
- 处理项目索引未就绪或没有可用 Agent。
- 处理上传、解析、索引和生成失败。
- 处理会话、运行器或终端断开。
- 处理无权限、权限被撤销和只读状态。
- 处理后台任务超时、重试和恢复。
- 保留未发送问题、草稿、附件选择和任务信息。
- 提供重试、重连、克隆、换模型、选择目录或安全退出操作。

## 二、主要组件

| 组件         | 包含内容                                 | 主要作用                       |
| ------------ | ---------------------------------------- | ------------------------------ |
| 应用入口     | 能力加载、身份判断、首次设置、路由       | 判断用户进入认证、审批或主应用 |
| 全局导航     | 项目入口、会话列表、搜索、收件箱、设置   | 切换项目、会话和系统功能       |
| 项目选择器   | 项目搜索、新建、编辑、删除、状态         | 管理当前投研项目               |
| 全局上传器   | 文件选择、公司识别、项目匹配、任务进度   | 将混合资料自动归入项目         |
| 项目资料库   | 上传、文件夹、文件列表、预览、批量管理   | 管理当前项目的原始资料         |
| 新研究编辑器 | 问题、项目、研究模式、附件、技能、Agent  | 创建新的研究会话               |
| 消息流       | 消息、推理、工具、命令、审批、引用       | 展示研究过程和结果             |
| 会话编辑器   | 输入、附件、语音、技能、上下文、生成控制 | 发起追问并控制生成             |
| 来源查看器   | PDF、Excel、Office、文本和引用定位       | 复核回答证据                   |
| 上下文选择器 | 资料、文件夹、研究资产和当前选择         | 控制本轮研究使用的内容         |
| 研究资产库   | 搜索、筛选、排序、预览、版本、删除       | 管理长期研究内容               |
| 内容查看器   | 文档、Markdown、表格、图表、HTML、证据   | 阅读不同类型研究内容           |
| Memo 管理器  | 生成、当前版本、历史版本、下载           | 管理 Memo 系列                 |
| 历史比较器   | 版本选择、变化摘要、证据变化、时间线     | 比较研究观点变化               |
| 估值面板     | 模型、指标、市场数据、差异、Agent 分析   | 跟踪估值变化                   |
| 追踪面板     | 风险、催化剂、提醒、规则、治理记录       | 持续跟踪研究事项               |
| 收件箱       | 审批、结构化问题、文件评论               | 集中处理待办协作事项           |
| 权限管理器   | 分享链接、成员、权限等级、撤销           | 管理会话协作权限               |
| 文件工作区   | 文件树、编辑器、差异和评论               | 处理 Agent 工作文件            |
| Agent 面板   | 主 Agent、子 Agent、状态和配置           | 查看与管理 Agent               |
| 终端面板     | Shell 列表、终端连接和重连               | 操作运行环境                   |
| 任务与日志   | 待办、执行状态和原始日志                 | 查看 Agent 执行过程            |
| 设置中心     | 语言、技能、主题、账号、模型和管理功能   | 配置用户与系统能力             |
| 通用反馈     | 加载、空、错误、确认、进度、提示         | 表达操作结果和异常状态         |

## 三、核心业务流程

### 1. 创建项目并开始研究

1. 创建或选择项目。
2. 上传项目资料。
3. 等待资料完成解析和索引。
4. 输入研究问题并选择研究模式。
5. 系统检查项目、索引和 Agent 状态。
6. 创建会话并自动发送首条问题。
7. Agent 返回带引用的研究结果。
8. 用户打开引用复核原始资料。

### 2. 全局上传并自动归档

1. 用户上传来自一个或多个公司的资料。
2. 系统识别每份资料所属公司。
3. 匹配已有项目或自动创建项目。
4. 无法识别的资料进入人工复核。
5. 用户手动修改资料归属。
6. 系统完成入库和索引。
7. 用户进入对应项目继续研究。

### 3. 使用上下文继续研究

1. 从项目资料或研究资产中选择内容。
2. 已选内容进入本次提问上下文。
3. 用户输入问题并选择文本、表格、图表或 Memo 输出。
4. Agent 使用会话历史和已选上下文生成结果。
5. 用户通过引用返回原始来源。
6. 用户调整上下文并继续下一轮研究。

### 4. 将回答沉淀为研究资产

1. 用户选择整条回答或部分内容。
2. 保存为答案笔记或研究资产。
3. 资产保留原会话、原回复和证据关系。
4. 新资产进入研究资产库。
5. 用户将资产加入后续提问或 Memo 生成上下文。

### 5. 生成并更新 Memo

1. 选择资料、笔记和研究资产。
2. 输入 Memo 主题和生成要求。
3. 系统生成新的 Memo 版本。
4. 用户查看、下载或继续修订。
5. 新资料进入项目后再次生成版本。
6. 选择两个版本进行比较。
7. 查看观点、证据和待复核项变化。

### 6. 估值跟踪

1. 上传或选择估值模型。
2. 系统读取模型版本、指标和期间。
3. 刷新实际数据和市场数据。
4. 查看模型值、实际值、缺失数据和差异。
5. 请求 Agent 分析估值影响。
6. 打开来源证据进行复核。
7. 需要时生成派生模型。
8. 用户确认后将派生模型加入项目资料。

### 7. 风险与催化剂追踪

1. 创建或启用观察规则。
2. 系统按事件或周期更新追踪项。
3. 新变化生成风险、催化剂或待复核提醒。
4. 用户打开详情查看判断、来源和版本变化。
5. 用户确认或忽略提醒。
6. 低质量记录进入治理流程。

### 8. 会话协作与审批

1. 会话所有者分享会话并设置权限。
2. 协作成员查看、评论或按权限编辑。
3. Agent 遇到受控操作时创建审批请求。
4. 请求进入会话和收件箱。
5. 用户批准、拒绝或回答结构化问题。
6. Agent 根据审批结果继续或停止。

### 9. 异常恢复

1. 系统识别上传失败、索引失败、会话断开或运行器不可达。
2. UI 保留当前输入、任务和会话信息。
3. 展示错误原因及影响。
4. 用户选择重试、重连、克隆、换模型或安全退出。
5. 恢复成功后继续原业务流程。
