# 告警策略

首次建立资料基线不为每个普通项目发送提醒。只有满足以下条件的新项目才可即时提醒：

- `quality_status=verified`；
- `confidence >= 0.80`；
- `impact` 为 `high` 或 `critical`。

已有项目在状态、时间、数值、概率或立场发生实质变化时可以提醒，但仍须证据有效且 `confidence >= 0.72`。

到期提醒只用于有明确时间窗口的非终态项目。相同项目、规则、变更和到期阈值只能产生一条提醒。

`critical` 仅用于可能改变核心投资结论、造成重大损失，或事件已经兑现、失败、取消。不要因为文案语气强烈而提高优先级。
